# Inoraxium — Griffin

Static GitHub Pages site for the Griffin story. The complete story text is embedded in index.html in source paragraph order; the page also works as a readable document when JavaScript is disabled.

## Local preview

Open index.html in a browser, or run a local static server from this folder. No build step or external library is required.

## GitHub Pages

The workflow in .github/workflows/pages.yml deploys the repository root after a push to main. In the repository settings, choose Pages → Build and deployment → GitHub Actions. The workflow uses GitHub’s current Pages actions (checkout v6, configure-pages v5, upload-pages-artifact v4, deploy-pages v4).

## Source material and media

- The story comes from the supplied inoraxium hikaye.docx; its wording, punctuation, chapter headings, and paragraph order are preserved.
- All 64 numbered scene images and all six character reference sheets are included. The PNG artwork was converted to high-quality JPEG (quality 92) with its original proportions and dimensions preserved for faster loading.
- All nine original MP3 files are included. Tracks named Sahne1.mp3 to Sahne9.mp3 are paired with Chapters I–IX by filename order; the supplied materials do not explicitly state this mapping, so the player labels it by sequence. Playback starts only after the reader presses Play.
- The story never names Griffin’s wife. One reference image has the filename “Elliana”; it is identified as a filename label in the gallery, not as a name stated in the story.

Publishing this repository publicly would make the full story, 64 scene illustrations, six reference images, and nine MP3 files public.
